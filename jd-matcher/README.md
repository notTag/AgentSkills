# jd-matcher

Analyze a job description against the candidate's engineering-leadership background and produce a structured fit analysis: numeric score, fit verdict, honest gap list, and positioning hooks. Output format is optimized for fast triage, tailored applications, and pattern-tracking across many roles.

## Trigger
Type the bare word `JDMatcher`, start a message with `ANALYZE_JD_FIT` followed by JD text, paste a JD with phrasing like "analyze this JD" / "score this role" / "is this a fit", or use `/JDMatcher` / `/jd-matcher`.
